# Polices locales du portfolio

Ces fichiers WOFF2 proviennent de Fontsource, qui redistribue les fichiers Google Fonts.
Leur contenu binaire est conservé sans modification. Le suffixe de chaque nom est
constitué des 12 premiers caractères de son SHA-256 ; il permet une mise en cache
longue et change automatiquement si une police est remplacée.

- Syne **v24** : variante variable normale, graisses **400 à 800** ; latin, latin étendu et grec.
- DM Mono **v16** : variantes normales, graisses **300, 400 et 500** ; latin et latin étendu.
- Les familles CSS restent `Syne` et `DM Mono`, avec `font-display: swap`.
- Seule Syne latin, utilisée dès le premier écran, est préchargée.
- Les autres fichiers sont demandés uniquement lorsque leurs caractères et graisses sont utilisés.
